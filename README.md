# Alpine.js e Desenvolvimento de Pacotes Laravel

Material prático da apresentação sobre Alpine.js, pacotes internos, Service Providers, auto-discovery e publicação de recursos.

- `projeto-inicial`: stack pronta e artefatos-base para desenvolver durante a aula;
- `projeto-final`: implementação completa e funcional do pacote `acme/laravel-feedback-widget`.

Comece pelo roteiro em `projeto-inicial/TESTING.md` e use o projeto final como referência e validação.
